# Bilingual technical glossary

| Spanish | English | Usage note | Do not use |
|---|---|---|---|
| backend | backend | Use as an adjective or noun for server-side application work. | back-end |
| API REST | REST API | Keep the acronym and capitalize REST. | RESTful service, unless the source specifically requires it |
| lógica de negocio | business logic | Use for application rules at a general level. | business rules, when it could imply confidential implementation detail |
| integración de pagos | payment integration | Use only in generic, anonymized content; use `external payment API` when a provider reference is needed. | provider-specific payment integration |
| plataforma de gestión educativa | education management platform | Preferred generalized description for the approved narrative and confidentiality matrix; do not identify an institution or product. | school management platform, unless an approved source uses that exact scope |
| sistema de gestión educativa | education management system | Use only when the approved source specifically supports a system rather than a platform; do not identify an institution or product. | school management system, unless the approved source uses that exact scope |
| tarea programada | scheduled task | Use for generic backend processing scheduled to run later. | cron job, unless the implementation detail is approved |
| comando Artisan | Artisan command | Retain the Laravel product name. | Artisan task |
| optimización de consultas | query optimization | Use without query, schema, benchmark, volume, or performance details. | database tuning, unless the source specifically supports it |
| consistencia de datos | data consistency | Use for reliable, coherent application data and flows. | data integrity, unless the source specifically requires it |
| sistema heredado | legacy system | Use for existing systems or code that require maintenance. | obsolete system |
| borrador | draft | Use for content that is not publicly available. | unpublished, when the publication state is not the point |
| publicado | published | Use for content that is publicly available through the intended publication workflow. | live, unless referring to an operational service |
